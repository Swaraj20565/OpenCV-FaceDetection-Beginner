# Face Detection using OpenCV

## Overview
This project captures an image from the webcam and detects human faces using OpenCV's Haar Cascade Classifier.

## Features
- Open webcam
- Capture an image
- Convert to grayscale
- Detect faces
- Draw a green rectangle around detected faces
- Display the result

## Technologies
- Python
- OpenCV

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python face_detection.py
```

## Output
- Opens the webcam
- Detects faces
- Draws green rectangles around detected faces
